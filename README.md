# ΕΙΣΑΓΩΓΗ
Σκοπός της εργασίας είναι η ανάπτυξη ενός εκπαιδευτικού λογισμικού που στοχεύει στην ενίσχυση της γνώσης και του ενδιαφέροντος για έναν πολιτισμικό ή τουριστικό πόρο. Το θέμα που θα τελούσε τον σκοπό αυτό είναι ένα ιστορικό μνημείο, μια τοπική παράδοση ή κάποιο τουριστικό προϊόν. Η περιοχή που καταλήξαμε να επιλέξουμε είναι το νησί Σπέτσες, οπότε, σε αυτή την περίπτωση, σκοπός της εργασίας είναι η ανάδειξη του πολιτισμού και της ιστορίας των Σπετσών. Το εκπαιδευτικό λογισμικό περιέχει υλικό (κείμενα, εικόνες, βίντεο) για την ιστορία, τον πολιτισμό, το φυσικό τοπίο και την καθημερινότητα στις Σπέτσεςκαι δραστηριότητες που ενθαρρύνουν χρήστες στην εμπέδωση του υλικού.

# ΑΡΧΙΤΕΚΤΟΝΙΚΗ ΤΟΥ ΛΟΓΙΣΜΙΚΟΥ
Το λογισμικό αποφασίσαμε να αναπτύξουμε είναι μια web εφαρμογή/ιστοσελίδα, η οποία θα περιέχει το προαναφερόμενο υλικό και δραστηριότητες, καθώς και σύστημα προόδου, σύστημα στατιστικών και μηχανισμούς που συμβάλουν στην προσαρμοστική μάθηση. Οι τεχνολογίες που χρησιμοποιήσαμε κατά την διαδικασία ανάπτυξης είναι οι εξής:
- Η γλώσσα προγραμματισμού C#
- Η αρχιτεκτονική asp.net mvc (model-view-controller)
- Το Entity Framework 9 για δημιουργία και διαχείριση βάσης δεδομένων μέσω C#
- Το προγραμματιστικό περιβάλλον Microsoft Visual Studio 2022
- Το SQL Server Management Studio 20 για σύνδεση του project με SQL Server
- Η τεχνολογία git για version control για διευκόλυνση συνεργασία καθώς αναπτύσσουμε το ίδιο λογισμικό



# Τεχνικές Λεπτομέρειες
Η βάση δεδομένων βρίσκεται σε SQL Server και δεν συμπεριλαμβάνεται στο project. Παρακάτω ακολουθούν οδηγίες για το πώς να εγκατασταθεί η βάση και πώς να εισαχθούν τα δεδομένα (Θεωρούμε ότι το SQL Server Management Studio είναι ήδη εγκατεστημένο).

1. Στον ίδιο τον κώδικα του project η μόνη αλλαγή που χρειάζεται να γίνει είναι στο connection string, το οποίο βρίσκεται στο αρχείο appsettings.json. Συγκεκριμένα η αλλαγή θα πρέπει να γίνει στο όνομα του server. Το όνομα του server πρέπει προφανώς να ταιριάζει με το όνομα server με το οποίο γίνεται σύνδεση στο Management Studio. Το υπόλοιπο string μπορεί να παραμείνει το ίδιο.

2. Στο terminal του IDE πρέπει να εκτελεστεί η παρακάτω εντολή η οποία δημιουργεί την βάση μέσω των migrations
-> dotnet ef database update 
ή εναλλακτικά στο Packet Manager Console του Visual Studio IDE 
-> Update-Database

3. Εφόσον η βάση δημιουργηθεί κανονικά μπορούν να εισαχθούν τα δεδομένα στους πίνακες τις βάσης εκτελώντας τα SQL αρχεία που παρέχουμε μέσω του Management Studio.
